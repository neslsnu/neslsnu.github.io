# NESL 홈페이지

서울대학교 항법전자시스템연구실(Navigation and Electronics System Lab) 홈페이지입니다.

기존 서버가 갑작스럽게 사라진 뒤, 옛 사이트의 구성을 되살리고 자료는 최신으로
채워 넣어 오래 쓸 수 있는 정적 사이트로 다시 만들고 있습니다. GitHub Pages로
배포합니다.

## 자료를 어디서 가져왔는지

두 곳을 함께 씁니다. 갈래마다 나은 쪽을 골랐습니다.

- **웹 아카이브** — 옛 사이트의 구성과 디자인, 그리고 현행 자료에 남지 않은 내용
  (학술대회·저서·학위논문 목록, 강의 교재, 게시판 기록, 협력기관 목록)
- **현재 운영 중인 임시 사이트** — 구성원, 연구 과제, 저널 목록, 강의 커리큘럼처럼
  최신이어야 하는 자료

어느 쪽을 썼는지는 각 페이지 상단에 밝혀 두었습니다.

## 페이지

상단 메뉴 여덟 개가 모두 실제 페이지로 이어집니다.

| 메뉴 | 내용 |
| --- | --- |
| RESEARCH | 4개 분야 16개 항목 |
| PROJECT | 진행 2건, 종료 6건 |
| MEMBER | 교수 1, 박사과정 7, 석사과정 3, 동문 63 |
| PUBLICATION | 저널·학술대회·저서·학위논문 396건 |
| LECTURE | 5과목 |
| BBS | 소식 6건, 갤러리 5건 |
| LINK | 협력기관 8곳 |
| LOCATION | 주소·연락처, 오시는 길 |

## 구성

```
index.html      대문
research/       연구 분야 (개요 + 4개 분야 페이지)
project/        연구 과제
members/        구성원
publication/    논문·저서
lecture/        강의
bbs/            게시판 기록
link/           협력기관
location/       찾아오시는 길
styles.css      전체 스타일
script.js       슬라이더·메뉴
assets/         이미지, 문서
```

## 로컬에서 확인하기

정적 파일이라 별도 빌드가 필요 없습니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 으로 접속합니다. 파일을 더블클릭해서 열면
`research/` 같은 디렉터리 주소가 이어지지 않으니 반드시 서버로 확인해 주세요.

## 되살리지 못한 것

아카이브에도 현행 자료에도 남아 있지 않아 복구하지 못한 부분입니다.

- **연구 분야 도표 35장** — 옛 사이트가 쓰던 `/images/sub01/` 경로가 아카이브에
  한 번도 수집되지 않았습니다. 임시 사이트도 같은 경로를 참조하지만 파일이 없어
  깨진 상태입니다. 자리와 설명만 남기고 표시해 두었습니다.
- **게시판 본문** — 게시판 주소가 수집된 적이 없습니다. 옛 대문에 실려 있던 최근 글
  목록에서 제목과 날짜만 건졌고, 그마저 3건은 제목이 잘려 있습니다.
- **갤러리 원본 사진** — 목록용 축소 이미지 4장만 남아 있습니다.
- **교수 소개 페이지(옛 버전)** — 본문이 전부 이미지로 되어 있었고 그 이미지가
  유실됐습니다. 현행 자료의 약력으로 대신했습니다.

## 연구실 확인이 필요한 것

- 대문 소개글의 구성원 수 — 임시 사이트에는 "박사과정 4명과 석사과정 9명"이라고
  적혀 있으나 실제 명단은 박사 7명, 석사 3명입니다. 숫자가 맞지 않아 해당 문장을
  빼 두었습니다.
- `실험실 302동 418-1호` — 옛 사이트 푸터에만 있고 현행 자료에는 없습니다.
  아직 쓰는 공간인지 확인이 필요합니다.
- 유실된 연구 도표 원본 파일이 연구실에 남아 있다면 넣을 수 있습니다.
  파일명은 `0101img01.jpg`, `1-3img01.jpg` 같은 형태입니다.

## 갱신할 때

구성원이나 과제처럼 자주 바뀌는 자료는 해당 페이지의 HTML을 직접 고치면 됩니다.
빌드 도구를 쓰지 않으므로 파일을 고치고 커밋하면 그대로 배포됩니다.
